RECALLFLOW 3.0 — INSTALL
1. Extract this ZIP and upload the CONTENTS of the folder to the root of your existing GitHub repository. Keep icons/icon.svg in its folder.
2. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save (if Pages is not already enabled).
3. Open the HTTPS Pages address in Android Chrome. Refresh once after deployment; if the old version remains, close and reopen the installed PWA after its service worker updates.

DATA
Topics, notes, revision history and image attachments are stored locally on this device/browser. No account, cloud backup or AI API is used. Export JSON backups regularly. The new version uses a fresh local data key; old topics are not migrated by design. Image attachments use IndexedDB; exports include them.

AI IMPORT
In the AI Import page, paste a JSON package generated by the ChatGPT study-processing conversation. Expected shape:
{"format":"recallflow-import-v1","entries":[{"name":"Topic name","subject":"Physics","category":"Mechanics","date":"YYYY-MM-DD","importance":"normal","coverage":{"studied":"...","understood":"...","practised":"...","needsWork":"..."},"keyPoints":["..."],"details":"...","note":"...","questions":["..."]}]}
A preview appears before import. Existing topics with the same name and subject are updated rather than duplicated. The sample-format button inserts a working example.

NOTES & IMAGES
Each topic has one consolidated entry with key points, formulas/details and personal notes. Multiple images can be attached from the topic editor; pasting an image while focused on a notes field is supported where the browser/WebView exposes clipboard image data.

REVISION
Initial cycle Day 1, 2, 4, 7, 14, 21, 28. After a confident Day 28 check, maintenance gaps are 1, 2, 3, 4, then 6 months. Red recall retries in 2 days; partial recall retries in 14 days.

NOTIFICATIONS
Browser notifications are checked when the app is open or brought back into focus, and periodically while it remains open. A browser-only PWA cannot reliably schedule notifications while fully closed. Reliable closed-app reminders require packaging as a native Android app with local-notification support; that is not included in this static PWA ZIP.

OFFLINE
The app shell is cached after the first successful HTTPS visit. Full revision and saved local data work offline after the app has loaded once.
